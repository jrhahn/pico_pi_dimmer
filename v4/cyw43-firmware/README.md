# CYW43439 firmware

Firmware, CLM and NVRAM for the Pico W's radio, as shipped in
[embassy at `cyw43-v0.7.0`](https://github.com/embassy-rs/embassy/tree/cyw43-v0.7.0/cyw43-firmware) for the
`cyw43` 0.7 crate. Embassy took them from
[georgerobotics/cyw43-driver](https://github.com/georgerobotics/cyw43-driver/tree/main/firmware).
